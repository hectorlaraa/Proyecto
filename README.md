Version 1
En esta versión comenzamos con el proyecto, creamos funciones para añadir aeropuertos, eliminar y generar graficas donde se representan los aeropuertos de la zona schenguen. Tambien utilizamos el google earth para mostrar la posición de los diferentes aeropuertos



Version 2


En la  versión 2 nos centramos en el aeropuerto de Barcelona, analizando las llegadas, las aerolineas y diferentes datos interesantes para la gestion de aeropuertos.
Cargamos un documento con las llegadas y a partir de este, generamos un grafico que representa las llegadas en ciertas zonas horarias, también guaardamos esta informacion
en un archivo. También generamos una serie de graficas que nos muestran los aviones que vienen de fuera de la zona schenguen y los que no. Finalmente, generamos en 
google earth la trayectoria de los diferentes aviones, de esta forma tenemos una información visual de el origen de cada vuelo 

En esta versión hemos solucionado los diferentes errores que habiamos tenido en la versión 1 y hemos completado la versión 1

Version 3


En esta version nos centramos en la estructura de una aeropuerto, con las aerolineas, boarding areas, gates y todo lo referente a la estructura de un aeropuerto. Hemos creado funciones para buscar los terminales de aerolineas, también para saber las puertas ocupadas. Ademas hemos creado un plot donde podemos observar la distribucion del aeropuerto.
Además, hemos implementado nuevas funciones a la ionterfaz, como una barra que nos permite deslizarnos en la interfaz, ya que esta se estaba haciendo pequeña a medida que aumentamos el numero de botones debido a las nuevas funciones.
